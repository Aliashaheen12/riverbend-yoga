THE GRADER NEEDS A WORKING LINK - DO THIS FIRST
-----------------------------------------------
1. Go to github.com and sign in. Click + (top right) > New repository.
   Name: riverbend-yoga   Visibility: PUBLIC   > Create repository.
2. Click "uploading an existing file". Open the website folder and drag
   EVERYTHING INSIDE IT (not the folder itself) into the page, so
   index.html ends up at the top level. Click "Commit changes".
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, / (root) > Save.
4. Wait 1-2 minutes, refresh. Copy the link shown, which looks like
   https://YOUR-USERNAME.github.io/riverbend-yoga/
5. Open the link in a private/incognito window and check all 4 pages work.


FINISH THE DOCUMENT
-------------------
In LastName_FirstName_Touchstone4.docx:
- Type your name
- Paste your GitHub Pages link into "Live preview link"
- Paste your repo link (https://github.com/YOUR-USERNAME/riverbend-yoga) into "GitHub repository"
- Rename the file with your real last and first name
Then resubmit the .docx on Sophia.


QUICK SELF-TEST ON THE LIVE SITE
--------------------------------
- Classes & Services: click "Beginner", pick "Morning", then "Save as my class". Reload the page.
  The filters and the saved class should still be there.
- Home: a "Welcome back" banner shows your saved class.
- Events: click "Add to my interests" on a workshop. Press "Send Request" with empty fields.
  Red messages appear under each field. Fix the fields and submit to see the confirmation.
